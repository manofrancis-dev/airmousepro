Simple gestures. Serious control.

Move

Point with your index finger and move naturally. Your hand motion becomes cursor motion.

+

Click / drag

+

Index + middle fingers together for scroll up / down without a physical wheel.

How to stop AirMouse Pro

When the app has no camera window, use the system tray:

01

Find the tray icon

Look near the Windows clock. Open the hidden-icons arrow if necessary.

02

Right-click AirMouse Pro

A small menu appears without opening a terminal.

03

Choose Exit

The app closes cleanly and releases camera/mouse control.

Good camera position

Use enough light and keep the hand inside the webcam view for stable tracking.

Smooth movement

The app includes smoothing for small tracking noise. Move deliberately rather than correcting rapidly.

Remember the map

Index = move. Index + thumb = left click/drag. Middle + thumb = right click. Index + middle = scroll.

SOURCE-ONLY • NO INSTALLER

Run from source.

AirMouse Pro is provided as source code. Clone the public GitHub repository, install its Python requirements, and run it directly on your Windows PC — no installer or packaged executable is used.

01

Clone the source repository

Open PowerShell or Terminal and clone the official source repository:

git clone https://github.com/manofrancis-dev/airmousepro.git
02

Install Python

Install 64-bit Python 3.10–3.12 from python.org (tick "Add python.exe to PATH" during installation).

03

Install dependencies

Open Terminal or PowerShell in the extracted folder and run:

python -m pip install -r requirements.txt
04

Launch

Start the app; it runs in the background with a system tray icon:

python main.py

TROUBLESHOOTING

Common questions.

Fast answers for first-time users.

Do I need Python installed?

Yes. AirMouse Pro runs from source using 64-bit Python 3.10–3.12 and the dependencies listed in requirements.txt.

Why does the app need my camera?

Hand gestures are detected through the webcam. Allow camera access for the application and keep your hand inside view.

The cursor feels shaky. What should I do?

Use brighter lighting, keep the hand comfortably inside the frame, and make deliberate movements. The app already includes smoothing for small tracking noise.

How do I stop the app?

Right-click the AirMouse Pro icon in the Windows system tray and choose Exit AirMouse Pro. You do not need to kill the process manually.
